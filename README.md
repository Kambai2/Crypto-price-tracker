# 🪙 Cryptoplace - Cryptocurrency Marketplace

A modern, professional cryptocurrency marketplace application built with React and Vite. Track real-time crypto prices, view market data, and explore detailed information about various cryptocurrencies with a sleek, glassmorphic UI.

![React](https://img.shields.io/badge/React-18.2.0-blue?style=flat-square&logo=react)
![Vite](https://img.shields.io/badge/Vite-5.0-646cff?style=flat-square&logo=vite)
![License](https://img.shields.io/badge/License-MIT-green?style=flat-square)

## ✨ Features

- 📊 **Real-time Crypto Data** - Fetch live cryptocurrency prices and market data from CoinGecko API
- 🔍 **Advanced Search** - Search and filter cryptocurrencies by name with autocomplete
- 💱 **Multi-Currency Support** - View prices in USD, EUR, and NGN
- 📈 **Interactive Charts** - View 7-day price trends with visual charts
- 🎨 **Modern UI/UX** - Professional glassmorphic design with smooth animations
- 📱 **Responsive Design** - Fully optimized for desktop, tablet, and mobile devices
- ⚡ **Fast Performance** - Built with Vite for lightning-fast development and production builds

## 🚀 Getting Started

### Prerequisites
- Node.js 16.x or higher
- npm or yarn package manager

### Installation

```bash
# Clone the repository
git clone https://github.com/Kambai2/Crypto-Price-Tracker.git

# Navigate to project directory
cd Cryptoplace

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will open at `http://localhost:5173`

## 📦 Build for Production

```bash
npm run build
```

## 🔧 Technologies Used

- **React 18** - UI library
- **Vite** - Build tool and dev server
- **React Router** - Client-side routing
- **CoinGecko API** - Cryptocurrency data source
- **CSS3** - Modern styling with animations and gradients
- **Context API** - State management

## 📂 Project Structure

```
src/
├── components/
│   ├── Navbar/          # Navigation bar component
│   ├── LineChart/       # Chart component for price trends
│   └── Footer/          # Footer component
├── pages/
│   ├── Home/            # Home page with crypto table
│   └── Coin/            # Individual coin details page
├── context/
│   └── CoinContext.jsx  # Global state management
├── App.jsx              # Main app component
```

## 💰 API Integration

This project uses the **CoinGecko API** for cryptocurrency data:
- Free tier with generous rate limits
- No authentication required for basic functionality
- Real-time price data and market information
